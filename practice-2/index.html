1. Что защищаешь и что открыть

«Посмотри в окно» показывает видео из разных городов. Слева плеер и форма поиска, справа заголовок и список карточек. Выбор карточки меняет ролик. Форма фильтрует выдачу по городу и времени суток.

  • Открой репозиторий проекта и основной CSS в сданной версии.
  • Для демонстрации запусти из папки проекта python -m http.server 8000 и открой http://localhost:8000/. Если сервер видео недоступен, покажи сохранённый скриншот, а механику поясни по коду.
  • Держи под рукой успешный прогон GitHub Actions и подтверждение приёмки Практикумом.
В сданной версии изменён основной CSS и добавлен README. Разметка, шаблоны и скрипт загрузки были в стартовом репозитории.

2. Маршрут показа на 3–5 минут

  1. 30 секунд. Назови задачу. Покажи плеер, форму, список и выделенную карточку.
  2. 45 секунд. При доступном API выбери другую карточку, введи город и отметь время суток. Для «Показать еще» вернись к широкой выдаче и прокрути список вниз. Кнопка появляется, если есть следующая страница.
  3. 60 секунд. Открой .content в DevTools. Покажи две колонки, зазор 30 px и выравнивание снизу. Затем найди overflow-y: auto у списка.
  4. 45 секунд. Нажми Tab, затем Пробел на чекбоксе. Покажи, как состояние :checked включает белый квадрат, а :focus-visible даёт рамку при работе с клавиатуры.
  5. 30 секунд. Покажи изменённые файлы, успешный тест и статус «Проверено».

3. Короткое объяснение своими словами

В этой практике я оформил интерфейс для просмотра видео из разных городов. В стартовом проекте уже были HTML и JavaScript. Основная работа была в CSS. Внешний Grid центрирует интерфейс, а Flexbox делит его на две колонки. Слева видео и форма, справа заголовок и список с собственной прокруткой. Чекбоксы работают как обычные поля формы, а их внешний вид задаёт CSS. Скрипт берёт фильтры из формы, запрашивает данные и создаёт карточки из шаблона. При выборе карточки он меняет адрес видео и обложку. Финальная версия прошла GitHub Actions и проверку Практикума.

6. HTML и шаблоны

<main> содержит основную часть страницы. В левой секции <video controls> даёт стандартные кнопки плеера, а <form> объединяет поля поиска. В правой секции находится <h1> и список <ul>, который заполняется после запроса.

Группы «Город» и «Время суток» находятся в <fieldset>. В этом шаблоне их видимые заголовки размечены через h2. Текст внутри label подписывает поле. Для города текст «Город» визуально скрыт, а подсказка внутри поля показывает пример ввода.

<input
  type="checkbox"
  name="time"
  value="morning"
  class="search-form__checkbox visually-hidden"
/>
<span class="search-form__pseudo-checkbox"></span>
<span class="search-form__label-text">Утро</span>

Эти три элемента вложены в один label. Клик по тексту или квадрату переключает input. Из отмеченных полей с именем time скрипт собирает значения morning, afternoon и night.

Разметка внутри template хранится отдельно от отображаемых узлов. Скрипт берёт template.content.cloneNode(true), заполняет копию и добавляет её на страницу. Есть шаблоны карточки, загрузки, ошибки и кнопки «Показать еще».

7. Как устроен CSS

Центрирование и две колонки

.content {
  display: flex;
  align-items: flex-end;
  gap: 30px;
  inline-size: 1140px;
}

.result {
  flex: 0 0 711px;
}

Grid на .page с place-items: center центрирует весь интерфейс. Внутри .content Flexbox ставит две колонки в ряд и выравнивает их по нижнему краю. Левая занимает 711 px и сохраняет эту ширину. Правая с flex: 1 получает остаток: 1140 − 711 − 30 = 399 px. inline-size и block-size в этой странице соответствуют ширине и высоте.

Grid страницы · Flexbox колонок

Плеер, карточки и прокрутка

Контейнер видео имеет высоту 386 px. Видео занимает его целиком, а object-fit: cover сохраняет пропорции и может обрезать часть кадра. Тот же принцип работает у миниатюр размером 194 × 103 px.

.content__list-container {
  position: relative;
  display: flex;
  flex-direction: column;
  gap: 30px;
  block-size: 298px;
  overflow-y: auto;
}

Прокручивается контейнер высотой 298 px. Внутренний список и кнопка «Показать еще» стоят друг под другом. Для заголовка карточки включены white-space: nowrap, overflow: hidden и text-overflow: ellipsis. У описания ограничение в четыре строки. min-inline-size: 0 позволяет текстовой части сжаться внутри Flexbox.

Контейнер списка · Размеры и текст карточки

Форма и кастомные чекбоксы

Форма использует Flexbox и justify-content: space-between. Кнопка «Найти» прижата к низу через align-self: flex-end. Рамка чекбокса имеет размер 19 × 19 px, а внутри неё по центру расположен квадрат 15 × 15 px.

.search-form__checkbox:checked + .search-form__pseudo-checkbox::after {
  opacity: 1;
}

+ выбирает следующий соседний элемент. Когда настоящий input отмечен, ::after у соседнего span становится видимым. Если переставить элементы, это правило перестанет срабатывать. Класс visually-hidden убирает поле визуально и сохраняет возможность получить фокус.

Состояния и слои

:hover подчёркивает текст при наведении, :active действует во время нажатия, :focus-visible показывает рамку, когда браузер считает нужным явно обозначить фокус, например при навигации клавишей Tab. У формы label:has(:focus-visible) обводит подпись целиком, когда фокус внутри неё. Класс content__card-link_current остаётся у выбранной карточки после клика, пока скрипт его не снимет.

Контейнеры видео и списка имеют position: relative. Загрузчик с position: absolute; inset: 0 покрывает соответствующий контейнер. Сообщение об ошибке по тому же принципу покрывает область видео.

8. Что делает готовый JavaScript

ДействиеЧто происходит в коде
Открытие страницыmainMechanics запрашивает данные с размером страницы в пять записей, рисует карточки и подставляет первое видео и постер. Первая карточка получает класс текущей.
Создание карточкиappendCards копирует шаблон. Из ответа берёт ID, город, описание и миниатюру. Текст записывает через textContent.
Поискform.onsubmit отменяет стандартную отправку формы через preventDefault(), очищает прежний список и запускает новый запрос. Функции разбора формы и запроса читают город и отмеченные значения времени суток.
Выбор карточкиchooseCurrentVideo отменяет переход по ссылке, переносит класс подсветки, находит запись по ID и меняет src и poster того же плеера.
«Показать еще»showMoreCards запрашивает следующую страницу с теми же фильтрами. Новые карточки добавляются к существующим. На последней странице кнопка исчезает.
Пустой ответ или ошибкаcatch при первичной загрузке или поиске показывает «Нет подходящих видео =(» для пустого результата либо «Ошибка получения данных :(» для других ошибок, затем убирает загрузчики.

После успешного запроса скрипт ждёт событие canplaythrough, затем выдерживает паузу 1200 мс и убирает загрузчики. Город добавляется в запрос с оператором $containsi, время суток с $eqi. Условия фильтрации обрабатывает API.

9. Что показать в DevTools

  1. Колонки. Открой F12 → Elements, найди .content и нажми метку flex. В Computed сверь 1140 px, зазор 30 px и ширины колонок.
  2. Прокрутка. Выбери .content__list-container и временно отключи overflow-y: auto. При длинном списке карточки выйдут за пределы контейнера. Верни свойство.

11. Возможные вопросы преподавателя

Что нужно было сделать и что уже было в шаблоне?

Оформить интерфейс: разместить колонки, плеер, список, карточки и форму, добавить состояния элементов. HTML, JavaScript и вспомогательные стили уже были. В принятой версии изменены styles/style.css и README.md.

Где применены Grid и Flexbox?

Grid с place-items: center центрирует весь интерфейс в .page. Flexbox размещает колонки в ряд, складывает карточки вертикально и выстраивает поля формы.

Почему колонки выровнены снизу?

align-items: flex-end ставит их нижние края на один уровень. При этом заголовок правой колонки может начинаться выше плеера.

Как получились 399 px справа?

У общего блока ширина 1140 px. Из неё вычитаем 711 px левой колонки и 30 px зазора. Оставшиеся 399 px забирает правая колонка с flex: 1.

Что значит flex: 0 0 711px?

Первый ноль отключает рост, второй отключает сжатие. 711px задаёт базовый размер по главной оси.

Зачем box-sizing: border-box?

Заданные размеры включают внутренние отступы и рамку. Например, в 19 px чекбокса уже входит его рамка в 1 px с каждой стороны.

Где задаётся прокрутка и зачем ограничивать высоту?

У .content__list-container высота 298 px и overflow-y: auto. Дополнительные карточки прокручиваются внутри, размер колонки от их количества не растёт.

Что делает object-fit: cover?

Вписывает видео или миниатюру с сохранением пропорций так, чтобы занять всю рамку. Если пропорции рамки и кадра разные, лишняя часть обрезается.

Почему одного text-overflow: ellipsis мало?

Для одной строки нужны ограниченная ширина, white-space: nowrap и скрытие переполнения. text-overflow: ellipsis задаёт отображение обрезанного края.

Зачем текстовому блоку min-inline-size: 0?

У flex-элемента автоматический минимум может зависеть от размера текста. Нулевой минимум позволяет блоку сжаться до доступной ширины и показать многоточие.

Как ограничены описание и заголовок карточки?

Заголовок в одну строку с многоточием. Описание ограничено четырьмя строками через -webkit-line-clamp: 4 в сочетании с display: -webkit-box, вертикальной ориентацией и скрытием переполнения.

Зачем label охватывает input и подпись?

Подпись связана с полем через вложение. Пользователь может кликнуть по тексту «Утро», и браузер переключит соответствующий чекбокс.

Как квадрат чекбокса узнаёт, что поле отмечено?

:checked совпадает с отмеченным полем. Селектор + находит соседний квадрат, а его псевдоэлемент ::after получает opacity: 1.

Почему чекбокс скрыт через visually-hidden?

Так сохраняются состояние поля, фокус и управление с клавиатуры. display: none убрал бы поле из обычного порядка фокуса.

Чем отличаются hover, active и focus-visible?

:hover действует при наведении, :active во время нажатия, :focus-visible при фокусе, который браузер считает нужным показать. Подсветкой выбранной карточки отдельно управляет JavaScript через класс.

Почему загрузчик не сдвигает страницу?

У него абсолютное позиционирование. inset: 0 растягивает его до краёв ближайшего позиционированного контейнера.

Зачем template и cloneNode(true)?

Один шаблон задаёт структуру всех карточек. true копирует также вложенные узлы, в которые скрипт подставляет данные.

Почему форма не перезагружает страницу?

Обработчик вызывает preventDefault(), после чего делает запрос через fetch и обновляет результаты в DOM.

Что меняется при выборе карточки?

Скрипт снимает класс текущей карточки с предыдущей ссылки и ставит на выбранную. По её ID находит запись и обновляет у существующего video атрибуты src и poster.

Как «Показать еще» узнаёт, что есть следующая страница?

Скрипт сравнивает pagination.page и pagination.pageCount из ответа. При равенстве кнопку больше не добавляет. Иначе запрос использует номер следующей страницы и прежние фильтры.

В чём разница между пустой выдачей и сетевой ошибкой?

Пустой список результатов вызывает ветку not-found с сообщением «Нет подходящих видео =(». Проблема запроса или разбора ответа при загрузке попадает в общую ветку «Ошибка получения данных :(».

Какие шрифты использованы?

Fira Sans Condensed используется для интерфейса, Oswald для крупных заголовков и названий городов. Файлы подключены через локальный @font-face в форматах WOFF2 и WOFF.

Что будет на телефоне?

У учебного проекта фиксированная ширина страницы 1200 px и раскладка без медиазапросов. На узком экране возможна горизонтальная прокрутка. Для адаптации понадобятся гибкая ширина и перестройка колонок.

Что именно прошло проверку?

В GitHub Actions успешен прогон Tests для коммита a875983. В ревью Практикума виден статус «Проверено». При локальной проверке интерактивность проверялась на тестовых данных и видео.

12. Самостоятельная тренировка

Если есть 15 минут, сначала проговори вступление, затем покажи в DevTools ширины колонок и чекбокс. Закрой ответы и ответь вслух на вопросы про шаблоны, запрос и пагинацию.

Задача A. Увеличь промежуток между колонками до 40 px. Какой станет правая колонка?

В DevTools поменяй у .content значение gap с 30 на 40 px. При прежних 1140 и 711 px справа останется 389 px. Проверь в Computed, затем верни 30 px.

Задача B. Замени object-fit у миниатюры на contain. Что изменится?

У .content__video-card-thumbnail поставь object-fit: contain. Вся картинка станет видна. При отличающихся пропорциях внутри рамки появятся свободные полосы. Размер самой рамки 194 × 103 px сохранится.

Задача C. Как проверить, что клик по «День» меняет состояние поля?

В Elements выбери input[value="afternoon"]. Нажми на его подпись в интерфейсе и введи в Console $0.checked. Значение переключится между true и false. Свойство checked показывает текущее состояние элемента.

Самопроверка. Назови цепочку от клика «Найти» до появления видео.

Событие submit → отмена стандартной отправки → очистка прежнего списка и показ загрузки → чтение города и чекбоксов → запрос к API → карточки из шаблона → установка первого ролика и постера → скрытие загрузчиков после готовности видео.

  • Изменения. CSS интерфейса и README с прямым URL. HTML и JavaScript из шаблона.
